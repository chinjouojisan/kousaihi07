# カコモと学ぶ 決算チャレンジ 公債費編

加古川市 令和7年度一般会計決算「公債費」(約86.2億円)を、クイズで学べる単一HTMLファイルのPWAです。

## 民生費・教育費との違い

公債費には、他の款のような「事業」の一覧がありません(seika_houkokusho_r7.xlsxの
事業一覧にも該当事業が0件)。元利償還金がほぼ全てを占め、事務事業評価の対象になって
いないためです。そのため今回は、本編シミュレーション層(29事業から選んで増額/維持/
減額を判断する形式)は作らず、以下の構成にしています。

1. **入口クイズ層**(9問、2択): 公債費とは何か、元金・利子の内訳比率、歳出総額に
   占める割合、支払先が非開示であることなど
2. **簡易カード層**: 「借入金元金償還事業」「借入金利子償還事業」の2枚のみ。
   いずれも契約に基づく返済義務のため「法定給付」(市の裁量では減らせないもの)
   として分類
3. **答え合わせ層**: 未実装(他の款と同様)

## データソース

- `kessansho_r7.xlsx`(歳出・款項別内訳、決算総額862,059.7万円)
- `kessan_meisai_r7.xlsx`(明細、元金・利子の内訳。支払先はいずれも非開示)

## 公開時の注意

- `og-image.png`は款名・金額入りのため作り直し済み(公債費・約86.2億円版)
- アイコン一式は民生費・教育費と共通のものをそのまま使用
